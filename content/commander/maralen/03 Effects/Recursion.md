# Recursion

Return a card from a graveyard to hand or the battlefield.

In this list the job is to replay the two legends and the engines, not to loop dorks.

**Priority targets:** [[02 Cards/Creatures/High Perfect Morcant|High Perfect Morcant]] or [[02 Cards/Creatures/Lathril, Blade of the Elves|Lathril]] (whichever the table still requires) → [[02 Cards/Creatures/Elvish Archdruid|Elvish Archdruid]] if Wave is in hand → [[02 Cards/Enchantments/Garruk's Uprising|Garruk's Uprising]] / [[02 Cards/Artifacts/Patchwork Banner|Patchwork Banner]] / [[02 Cards/Artifacts/Panharmonicon|Panharmonicon]] / [[02 Cards/Enchantments/Kindred Discovery|Kindred Discovery]].

**Outlets**

- Any permanent: [[02 Cards/Creatures/Golgari Findbroker|Golgari Findbroker]], [[02 Cards/Creatures/Elvish Regrower|Elvish Regrower]]
- Another Elf, on death: [[02 Cards/Creatures/Morcant's Loyalist|Morcant's Loyalist]]
- Named type from the yard: [[02 Cards/Artifacts/Dawn-Blessed Pennant|Dawn-Blessed Pennant]] (name Elf)
- Soft: [[02 Cards/Creatures/Champions of the Perfect|Champions of the Perfect]] returns the beheld Elf when it leaves
